📊 Sales Analysis Dashboard – Excel

⚙️Project Overview

This project is an interactive Sales Analysis Dashboard created in Microsoft Excel. It is designed to analyze sales performance and provide useful business insights through data analysis, reports, and visualizations.
The project uses a sales dataset containing 500+ records with information about orders, customers, products, regions, sales, costs, profit, payment modes, shipping, and order status.

 🎯 Project Objective
The main objective of this project is to transform raw sales data into an easy-to-understand dashboard that can help identify **sales trends, profitable products, regional performance, and overall business performance**.
